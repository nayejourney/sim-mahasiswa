# Dokumentasi dan Screenshot

Simpan screenshot terminal yang menunjukkan program berhasil berjalan dan pengujian yang lulus di folder ini. Contoh nama file:

- `program-menu.png` — menu utama aplikasi.
- `daftar-mahasiswa.png` — contoh daftar mahasiswa.
- `pytest-result.png` — hasil pengujian otomatis.

Screenshot harus diambil dari hasil eksekusi program sendiri, bukan gambar contoh yang dibuat-buat.
